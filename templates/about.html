ABOUT THE PROJECT

Photo guidance with context.

Plant Doctor uses automatic image analysis to suggest a likely plant and possible condition, then explains it with India crop-guide information.

How it works

A photo is sent securely from the website server to the image-analysis service for one check. The API key stays private and is never shown in the browser.

Optional account

Google sign-in is optional. The site does not keep uploaded photos after the result is sent, and no daily application limit is active.

India crop guide

The guide includes common field, vegetable, fruit, spice and plantation crops across India for clear comparison and responsible next steps.

Limitations

Photos can be unclear and different problems can look alike. Treat each result as a possible match; consult a qualified local agricultural professional for serious or spreading issues.
