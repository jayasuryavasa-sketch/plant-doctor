ABOUT THE PROJECT

Thoughtful technology for plant care.

Plant Doctor is a Flask web application built for learning and demonstration.

How it works

A browser sends a validated leaf photo to the Flask backend. A prediction module then uses a lightweight MobileNetV3 transfer-learning checkpoint when one is installed. The separate disease-information data layer turns a model label into readable care guidance.

Model & data

This project is ready to train on a properly licensed PlantVillage-style folder dataset. Until a checkpoint is trained and added, the interface deliberately runs in demo mode and marks each result uncertain—it does not make a diagnosis.

Limitations

Image classifiers can be wrong, especially with poor images, unsupported plants, multiple problems, pests, or real-world growing conditions unlike training data. Confidence is a model score, not a guarantee.

Responsible use

AI-generated results are informational only. For severe, unusual, or uncertain cases, consult a qualified agricultural professional or local agricultural extension service.
